# Thymeleaf Validator Frontend

React-based interface for the Thymeleaf Validator.

## Technologies
- React
- Vite
- PrismJS (Syntax Highlighting)
- React Simple Code Editor

## Getting Started

### Prerequisites
- Node.js 20+
- npm

### Running Locally
```bash
npm install
npm run dev
```

### Building with Docker
```bash
docker build -t thymeleaf-validator-frontend .
```

## Features
- Real-time template analysis
- Variable extraction and dynamic form generation
- Live HTML rendering
- Undo/Redo support
- HTML export/download
